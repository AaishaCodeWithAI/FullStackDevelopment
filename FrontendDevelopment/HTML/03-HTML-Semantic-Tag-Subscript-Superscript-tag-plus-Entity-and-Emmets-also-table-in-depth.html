  1. Superscript vs Subscript Tags

    • Superscript Tag

      It is a tag which helps us to write formula and powers; where it comes at top
      and are small in size.

      For example: (a+b)2

    • Subscript Tag

      It is a tag which helps us to write formula; where it comes at bottom and are
      small in size.

      For example: H2O

  2. Semantic vs Non-Semantic Markup

    • Semantic Makeup

      It is the makeup that relates to the meaning of the content. It is used to make webpages
      meaningful, and the layout structured. It makes the wepages SEO(Search Engine Optimization)
      friendly. It helps to make website more readable and improve user experience.

      Common Example of Semantic Tags are:

      • Header

        To write header (top) block.

      • Main

        To write the main body block.

      • Footer

        To write the footer (bottom) block.

      • Nav

        To write a collection of links block.

      • Article

        To write independent block like blog, article, anouncement, news, etc.

      • Section

        To divide structure into different sections of related informations.

      • Aside

        To write the content that is indirectly related to the main content of the
        page or section.

    • Non-Semantic Makeup

      It is the makeup that doesn't relate to the meaning of the content.They can be used with
      different attributes to mark up semantics common to a group.

      Common Exmaple of Non-Semantic Tags are:

      • Div
      • Span

  3. Some Important elements of HTML:

    • Entity

      Entity is the special code that either are reserved meaning in html, can't be typed directly,
      or are special symbols.

      It ensures that the browser displays the character correctly instead of interpreting it as,
      HTML code.

        Common example of Entities are:

      • & - And Symbol using &amp;
      • < - Less than symbol using &lt;
      • > - for greater than symbol using &gt;
      • " - for double quotation symbol using &quot;
      • ♥ - for heart symbol using &hearts;

      These symbols can't be directly displayed in brower through html as they are reserved and special
      symbols ones.

      To represent these symbol, we have to write: ("& + certain specific name + ;") or we can
      also write certain number code for these symbols from brower and use it.

      For more such entities:

    • Emmets

      A essential toolkit which contains Collection of tools necessary for web developers that lets us write
      HTML and CSS much faster using short abbreviations that expand into full code snippets.

        Common Example of Emmets are:

      • ! - For bollerplate code of html
      • !!! - For html5
      • ul>li*3 - For unordered list with three listing dataspace.
      • nav>ul>li*4>a - Nested navigation list with 4 links
      For more such emmets

    Tables in HTML are used to represents real-life table data. It consists
    rows and columns.

      • Student List

    • Semantics in Tables

      Even the tables got semantic markup. It contains:

      • thead - to wrap table header.
      • tbody - to wrap table body.
      • tfoot - to wrap table footer

    • Table ColSpan & RowSpan Attributes

      Used to create cells which spans over multiple rows and columns.
