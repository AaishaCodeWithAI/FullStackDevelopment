    • HTML Boilerplate

      HTML Boilerplate is the basic template or skeleton of every HTML document.
      It contains the essential elements required for a web page to function correctly
      in modern web browsers.
      It serves as the starting point of any HTML.

      Basic Boilerplate of HTML

      <!DOCTYPE html> <html lang="en">    <head>      <meta charset="UTF-8">      <meta name = "viewport" content="width=device-width, initial-scale=1.0">    </head>    <body>    </body> </html>

      Note: Write '!' in html document, then select it,and we will get the ready-made boilerplate for html.

      Explantion of Boilerplate

      •  <!DOCTYPE html>

        It tells the browser that the document is written in HTML5, the latest version of HTML.
        It helps the browser display the webpage correctly.

      •  <html>

        It is the root element of every HTML document. All other HTML elements are written inside this tag.

        Example:
         <html>
         </html>

      •  lang = "en"

        The lang attribute specifies the language of the webpage. It helps search engines, browsers, and screen
        readers understand the page's language.

        Example:
         <html lang = "en">

        Note:The lang attribute does not translate a webpage or make it multilingual.
        It simply specifies the primary language of the document (or a specific element), helping browsers, search
        engines, screen readers, and other tools interpret the content correctly.

      •  <head>

        The head section contains information about the webpage, not the visible content.
        It usually contains:

        • Title
        • Meta tags
        • CSS and JS links
        • Icon (Favicon)
        The content inside the <head> tag is not displayed on the webpage.

      •  <meta charset = "UTF-8">

        It specifies the character encoding used by the webpage. By charcter encoding, it
        means that they tell the browser which charcter encoding to save the HTML file to
        display the text correctly. As, we know computer doesn't store letters directly-they
        store binary numbers (0s and 1s). And, the charcter encoding is the standard that maps
        these numbers to charcter.
        While UTF-8 supports almost every charcter and symbol from different languages. It also
        allows special symbols and emoji to display correctly. Without it, some charcters may appear
        as strange symbols or question marks.

      •  <meta name = "viewport" content = "width=device-width, initial scale=1.0">

        It makes the webpage responsive on different devices like mobiles, tablets, and laptops.
        Without this tag, webpages may not display properly on smaller screens.

      •  <title>

        The <title> tag specifies the title of the webpage.
        The title appears:

        • On the browser tab
        • In bookmarks
        • In search engine results
        Example:
         <title>My Portfolio</title>

      •  <body>

        The tag contains all the visible content of the webpage. Everything users see is
        written inside this tag. Examples include:

        • Headings
        • Paragraphs
        • Images
        • Lists
        • Forms
        • Tables
        • Videos

    • HTML Structure

      HTML is mainly divided into two sections.

      Head Section

      • <title>: Page title
      • <meta>: Metadata
      • <link>: External CSS files
      • <script>: Javascript files
      • <style>: Internal CSS
      • <base>: Base URL for relative links

      It is not displayed to users.

      Body Section

      he Body section contains everything that is visible to the user.It contains visible content of
      the webpage, used to creating the webpages interface.

      It includes: All elements which users see.
      • Headings
      • Paragraphs
      • Images
      • Lists
      • Forms
      • Tables
      • Videos
      • Hyberlinks
      • buttons

    • Inline vs Block Elements

      • Block Elements

        Block Elements takes up the entire width no matter necessary
        or not for them, and they always begin from next line

      • Inline Elements

        Inline Elements only takes the width necessary for them,
        and they don't begin from next line

        Anchor Tags are Inline Element.

        Image tags are also Inline Element.

    • Div vs Span Element

      • Div Element

        • It is also known as content division element. It just a container to hold
        other tags and group them together

        It is a block element

      • Span Element

        • It is a generic container used to hold other html elements or group elements
        together.
