    Part-2: CSS

  • Selectors in CSS

    • Universal Selector:

      To select everything in the document.

      Example:
      * {
      property:value;
      }
      where '*' is the universal selector.

    • Element Selector:

      Select all elements of the same type.

      Example: h1 {
       property:value;
      }
      where 'h1' is the element selector.

    • ID Selector:

      Select an element based on the value of the elements id alternative.

      Example: #myId {
       property:value;
      }
      where 'myId' is the id selector and always remember to put '#' ahead of any id selector.

    • Class Selector:

      Selects an element based on their class attribute.

      Example: .myclass {
       property:value;
      }
      where 'myclass' is the class selector and always remember to put '.' ahead of any class selector.

    • Descendent Selector

      Selects all paragraphs inside divs.

      Example: div p {
       property:value;
      }
      where 'div p' is the desecendent selector and always remember to have gap in between.

    • Sibling Combinator:

      Heading 3 that comes immediately after any paragraph.

      Example p + h3 {
       property:value;
      }
      where '+' is the sibling combinator.

    • Child Combinator:

      Selects all buttons within which are direct children of spans.

      Example: span > button {
       property: value;
      }
      where '>' is the child combinator.

    • Attribute Selector:

      Selects element based on the presence or value of a given attribute.

      Example: input [attr = "value"] {
       property: value;
      }
      where input [attr = "-"] is the attribute selector.

  • Pseudo Class:

    A keyword added to a selector that specifies a special state of the selected element(s).

    • :hover
    • :active
    • :checked
    • :nth-of-type

  • Pseudo Element:

    A keyword added to a selector that lets you style a specified part of the selected elements.

    • ::first-letter
    • ::first-line
    • ::selection

  • CSS:Cascading Style Sheets:

    Cascade in CSS:
    The CSS cascade algorithm's job is to select CSS declaration in order to determine the correct values for CSS properties. (for same selector)

    Selector Specificity (for different selector):

    An algorithm that calculates the weight that is applied to given CSS declaration.

    _____ id ________ class, attribute and pseudo-class ________ element and pseudo element

    • id>class>element
    • more sector ^ CSS > less sector
    • if specificity is the same, we check cascading.

    Inline Specificity:

    Inline Styles are more specific than id.

    _____ inline style _______ id ______ class, attribute and pseudo-class ________ element and pseudo element
