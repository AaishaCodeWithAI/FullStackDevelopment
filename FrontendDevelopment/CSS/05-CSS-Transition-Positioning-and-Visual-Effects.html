  • CSS Transitions

    It enable us to define the transition between two states of any element.

    Example:

    Click me

    (Transistion Phase) > (When we hover)

    Me after you clicked.


    In CSS:

       div {
         height: 200px;
         width: 200px;
         background-color:aqua;
         transition-duration:1s;
       }

       div:hover {
         background-color:skyblue;
         border-radius: 50%;
       }

    Transition-Shorthand

    Property Name | duration | timing-function | delay

    Example:
       margin-top 2s ease-in-out 0.2s;

      Transition-Elements

    • Property Name:

      Specifies which CSS property should animate.

      Example:

      • transition: background-color 0.3s;
        background-color: Only the background color changes smoothly.
      • transition: opacity 1s;
        Opacity: Only the opacity changes.
      • transition: all 0.4s;
        all: Every animatable property transitions.

    • Duration:

      Specifies how long the transition takes.

      Example:
          transition: all 0.5s;
          transition: background-color 0.3s;
      Note: Without a duration, the transition wouldn't be visible.

    • timing-function:

      Controls the speed curve of the animation.

      Common Values:

      • ease (default)- Starts slow, speeds up, ends slow.
      • linear - Contatant Speed
      • ease-in - Starts Slow
      • ease-out - Ends Slow
      • ease-in-out - Starts and Ends Slow

      Example:
          transition: opacity 0.5s ease-in-out;

    • delay:

      Specifies how long to wait before the transition starts.

      Example:
          transition: background-color 0.5s ease 2s;
      It means: It waits 2s, then animate for 0.5s.

  • CSS Transform

    This property lets us to rotate, scale, skew, or translate on element.

    • Rotate():

      transform: rotate (45 deg);
      Metrics can also be radian, and turns too.
      It rotates clockwise using degrees, negative degree rotate counter clockwise.

    • Scale():

      Resize an element (simply changes the size).
      transform: scale (1.2);
      It is original size, then 1.2 -> 20% larger.
      transform: scaleX(1.5); - width only.
      transform: scaleY(2); - height only.

      Common Hover Effect:

      In CSS

      .box : hover {
         transform: scale (1.05);
      }
      It will enlarge 5%

      translate():
      Move an element from its original position.
      transform: translate (50px , 20px); where 50px moves towards right, and 20px moves towards down.

      Individual directions:
      transform: translateX (100px); for right
      transform: translateY (50px); for left

  • Box Shadow

    It adds shadow effect around an element's frame.
    box-shadow: 2px 2px 10px green; where 1st 2px is to move towards right, then 2nd one towards bottom, 10px for blurring, and color of shadow.
