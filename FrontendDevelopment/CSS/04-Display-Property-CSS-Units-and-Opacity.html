  • Revision: Inline vs Block Elements

    Block Elements

    Takes up the full-width available (whole block). It starts from the new line.

    Inline Elements

    Takes up only necessary width required for its self.

  • Display

    Before we learned about inline and block.

    It sets wheather an element is treated as a block or a inline element and the layout used for its children.

    Example:
        display: inline;
        display: block;

  • Display with inline-block

    When we set any element's display to inline-block; then the element style is according to block, but it behaves as inline element.

    Example:
       div {
         display:inline-block;
       }

    Note: We use display: none; to hide an element's display.

  • Revision: Units in CSS

    Absolute Relative
    px %
    pt em
    pc rem
    cm ch
    mm rh
    in rw + many more

  • Percentage (%)

    It is often used to define a size as relative to an element's parent object.

    Example:
       width: 33.33% //relative to the parent.
       margin-left: 50% //relative to the parent size.

  • Em

    It is often used to define the font-size with respect to its parents, in case of typographical properties like font-size, and with respect to itself, in case of other properties like width.

    Example:
       div {
         font-size: 0.5em; //means half of the parent's font-size.
         padding: 1em; //means exact same padding as its respect to its font-size element.
       }

    Drawback of em

    Snowball effect in nested elements.

  • Rem

    It was brought to counter the drawback of em. Rem (Root em). It is often used to define font-size of the element with respect to its root element.

  • Alpha Chanel

    Sets the opacity for a color.
    Alpha range: 0-1 / 00-ff
    0 -> Hidden
    rgba (255, 255, 255, 0.3)

  • Opacity

    Sets the opacity for the element.
    Range from 0 to 1
    0 -> Hidden
    Example: opacity: 0.5;
