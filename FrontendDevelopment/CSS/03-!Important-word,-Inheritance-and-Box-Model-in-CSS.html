!important:

  • Not used often in class.
  • To show the most specific thing in document.
  • hightest property stuff in CSS Style Sheet.

Inheritance in CSS:

Inheritance in CSS is the mechanism by which certain properties are automatically passed down from a parent element to its child elements.

Example:
   div {
   background-color: red;
   }

The hierarchical level:

   In div
   |
   p
   |
   ul
   |
  li (li inherit properties from div)

    Properties that can't be inherited:

  • width
  • height
  • border and many more

Box Model in CSS:-

  • Height:

    By default, it sets area height of the element.

    Example

       div {
       height: 100px;
       }

  • Width:

    By default, it sets content area width of the element.

    Example

       div {
       width: 300px;
       }

  • Border:

    It is used to set the element's border.

    • border-width
    • border-style
    • border-color

    Example

       div {
       border-width: 2px;
       border-style: solid;
       border-color: red;
       }

    Border Shorthand:


    width|style|color

    Example:

       div {
       border: 2px|solid|red;
       }

    Border Slides:


    It is used to control an individual slide of the box.

    Example:

       div {
       border-left-color: black;
       border-left-style: dashed;
       }

    Border radius:


    It is used to round the corners of an element's outer border edge.

    Example:

       div {
       border-radius: 15px;
       }
       div {
       border-radius: 50%;
       }
    where 50% turns box into circle.

    We can control the individual sides of the corner of the box.

    Example:

       div {
       border-top-right-radius: 15px;
       }

  • Padding:

    It is used to control remaining area of the box after the content.

    Example:

       div {
       padding-top: 10px;
       }

    Padding Shorthand:

    • For all 4 slides:

      padding: 50px;

    • For top and bottom|left and right slides:

      padding: 1px 2px;

    • For top | left and right | bottom slides:

      padding: 1px 2px 3 px;

    • For *clockwise, top|right|bottom|left slides:

      padding: 1px 2px 3 px 4 px;

  • Margin:

    It is used to set spacing on the outside thr border for between two boxes.

    Example:

       div {
       margin-left: 50px;
       }

    Margin Shorthands:

    • For all 4 slides:    

      margin: 50px;

    • For top and bottom|left and right slides:    

      margin: 1px 2px;

    • For top | left and right | bottom slides:    

      margin: 1px 2px 3 px;

    • For *clockwise, top|right|bottom|left slides:    

      margin: 1px 2px 3 px 4 px;
